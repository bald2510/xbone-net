HƯỚNG DẪN CÀI ĐẶT XBONE-NET
============================

1. THƯ MỤC GỐC CỦA CHƯƠNG TRÌNH
--------------------------------
Trong tài liệu này, <XBONE_ROOT> là thư mục chứa trực tiếp các tệp train.py,
evaluate.py, inference.py và requirements.txt. Mọi lệnh phải chạy tại đây.

Windows PowerShell hoặc CMD:

  cd <DUONG_DAN_DEN_XBONE_ROOT>

Linux:

  cd <DUONG_DAN_DEN_XBONE_ROOT>

Không chạy lệnh bên trong package Python <XBONE_ROOT>/src.


2. YÊU CẦU HỆ THỐNG
-------------------
- Windows 10/11 64-bit hoặc Linux 64-bit.
- Python 3.11; môi trường đã kiểm tra dùng Python 3.11.15.
- Miniconda hoặc Anaconda.
- NVIDIA GPU và CUDA được khuyến nghị. Demo có thể chạy CPU nhưng tải model và
  tính Integrated Gradients sẽ chậm.
- Ít nhất 10 GB dung lượng trống.
- Kết nối Internet trong lần đầu để pip và OpenCLIP tải pretrained BiomedCLIP.


3. TẠO MÔI TRƯỜNG PYTHON
------------------------
  conda create -n Thesis python=3.11.15 -y
  conda activate Thesis
  python -m pip install --upgrade pip setuptools wheel

Kiểm tra đúng môi trường:

Windows:
  python --version
  where.exe python

Linux:
  python --version
  which python


4. CÀI PYTORCH VÀ CÁC THƯ VIỆN
------------------------------
NVIDIA GPU, CUDA 12.8:

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128

Chỉ dùng CPU:

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu

Cài phần còn lại tại <XBONE_ROOT>:

  python -m pip install -r requirements.txt

MedCLIP chỉ cần cho baseline MedCLIP, không cần để chạy demo:

  python -m pip install --no-deps MedCLIP==0.0.3


5. TÀI NGUYÊN BẮT BUỘC CỦA DEMO
-------------------------------
Bản phát hành demo phải giữ nguyên cấu trúc:

  demo/model/
  |-- best_phase2.pth
  |-- metrics.json
  |-- manifest.json
  `-- features/
      |-- ctch_train.npz
      `-- ctch_val.npz

Đây là checkpoint seed 42 của ctch/proposed/ours_xbone_net cùng các feature
archive được trích xuất từ chính checkpoint đó. Ứng dụng tự phát hiện thư mục
demo/model; không cần đặt biến môi trường khi dùng cấu trúc mặc định.

Kiểm tra checksum và kiến trúc trước khi chạy:

  python tools/verify_demo_artifacts.py

Kết quả đúng phải có dòng:

  Demo artifacts: OK

Nếu đặt tài nguyên ở thư mục khác, khai báo trước khi chạy.

Windows PowerShell:
  $env:XBONE_DEMO_ARTIFACT_ROOT="D:\duong-dan\model"

Windows CMD:
  set XBONE_DEMO_ARTIFACT_ROOT=D:\duong-dan\model

Linux:
  export XBONE_DEMO_ARTIFACT_ROOT=/duong-dan/model


6. DỮ LIỆU CHO HUẤN LUYỆN VÀ ẢNH THAM CHIẾU
--------------------------------------------
Checkpoint và feature archive trong demo/model đủ để nạp model, hiệu chỉnh
confidence và OOD. Để giao diện hiển thị ảnh CTCH-train tương tự, cần thêm ảnh
theo đúng image_id tại:

  data/CTCH/images/

Nếu không phân phối ảnh CTCH do giới hạn quyền sử dụng dữ liệu, demo vẫn dự
đoán, phát hiện OOD và tính IG; vùng ảnh tương tự sẽ báo không tìm thấy tệp.

Để huấn luyện lại, cần chuẩn bị thêm:

  data/CTCH/ctch-split.csv
  data/CTCH/ctch-labels.csv
  data/CTCH/images/
  data/CTCH/reports/clinical/

Dữ liệu bệnh nhân không được đưa vào kho mã nguồn công khai nếu chưa được phép.


7. KIỂM TRA CÀI ĐẶT
-------------------
Chạy lần lượt tại <XBONE_ROOT>:

  python -c "import torch; print('PyTorch:', torch.__version__, '| CUDA:', torch.cuda.is_available())"
  python -c "import hydra, numpy, pandas, sklearn, streamlit, transformers; print('Core libraries: OK')"
  python tools/generate_requirement.py --check
  python tools/verify_demo_artifacts.py
  python -m compileall -q train.py evaluate.py inference.py src tools benchmark demo


8. LỖI THƯỜNG GẶP
-----------------
- ModuleNotFoundError: kích hoạt lại bằng "conda activate Thesis" và kiểm tra
  terminal đang đứng tại <XBONE_ROOT>.
- Missing demo artifact: kiểm tra đủ bốn tệp được liệt kê trong manifest.json.
- Sai SHA-256: không trộn checkpoint và feature archive từ các lần huấn luyện
  khác nhau; đóng gói lại theo HuongDanSuDung.txt.
- Không tải được BiomedCLIP: kiểm tra Internet và cache Hugging Face/OpenCLIP.
- CUDA out of memory: chọn CPU trong demo hoặc giảm số bước IG.
- MedCLIP dependency conflict: cài requirements.txt trước, sau đó cài MedCLIP
  với --no-deps.
