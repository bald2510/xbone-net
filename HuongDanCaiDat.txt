HƯỚNG DẪN CÀI ĐẶT XBONE-NET
============================

1. PHẠM VI GÓI MÃ NGUỒN
-----------------------
Gói nộp có cấu trúc:

  MaDeTai/
  |-- src/                   Mã nguồn và cấu hình có thể thực thi
  |-- HuongDanCaiDat.txt     Tài liệu này
  `-- HuongDanSuDung.txt     Hướng dẫn biên dịch và chạy

Thư mục MaDeTai/src là thư mục gốc của chương trình, tức thư mục chứa train.py
và requirements.txt. Bên trong có các entrypoint train.py, evaluate.py,
evaluate_ood.py, inference.py; package Python src/; cấu hình Hydra configs/;
benchmark/; demo Streamlit trong demo/; công cụ tools/; launcher Windows trong
scripts/; và mã tiền xử lý dữ liệu trong data/.

Gói KHÔNG chứa thư viện bên thứ ba, môi trường Python, dữ liệu bệnh nhân, ảnh,
report, pretrained weights, checkpoint, kết quả, log, cache hay file trung gian.
File requirements.txt chỉ là danh sách phiên bản để cài thư viện, không phải thư
viện đã đóng gói.


2. YÊU CẦU HỆ THỐNG
-------------------
- Hệ điều hành: Windows 10/11 64-bit hoặc Linux 64-bit.
- Python: 3.11.15.
- Công cụ quản lý môi trường: Miniconda hoặc Anaconda.
- GPU NVIDIA và driver tương thích được khuyến nghị khi huấn luyện.
- CPU có thể dùng để kiểm tra hoặc suy luận nhỏ nhưng chậm hơn đáng kể.
- Cần đủ dung lượng riêng cho dữ liệu, cache pretrained model và checkpoint.
- Cần Internet trong lần đầu tải pretrained weights.


3. MỞ THƯ MỤC CHƯƠNG TRÌNH
--------------------------
Mọi lệnh huấn luyện, đánh giá và suy luận phải chạy tại MaDeTai/src để các
đường dẫn Hydra tương đối được phân giải đúng.

Windows PowerShell/CMD:

  cd <DUONG_DAN_DEN_GOI_NOP>\MaDeTai\src

Linux:

  cd <DUONG_DAN_DEN_GOI_NOP>/MaDeTai/src


4. TẠO MÔI TRƯỜNG PYTHON
------------------------
  conda create -n Thesis python=3.11.15 -y
  conda activate Thesis
  python -m pip install --upgrade pip setuptools wheel

Kiểm tra terminal đang sử dụng đúng môi trường:

  python --version

Windows:

  where.exe python

Linux:

  which python


5. CÀI PYTORCH
--------------
Môi trường đã kiểm thử sử dụng PyTorch 2.11.0, torchvision 0.26.0 và CUDA 12.8.

GPU NVIDIA:

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128

Chỉ dùng CPU:

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu


6. CÀI CÁC THƯ VIỆN CỦA DỰ ÁN
-----------------------------
Tại MaDeTai/src, chạy:

  python -m pip install -r requirements.txt

requirements.txt khóa phiên bản của các thư viện trực tiếp và runtime gồm:
accelerate, deep-translator, evaluate, hydra-core, matplotlib, nltk, numpy,
omegaconf, open-clip-torch, pandas, peft, Pillow, PyYAML, requests,
scikit-learn, scipy, streamlit, tensorboard, timm, torch, torchvision, tqdm,
transformers và wget.

Chỉ khi chạy cấu hình dùng MedCLIP, cài thêm riêng bằng lệnh sau:

  python -m pip install --no-deps MedCLIP==0.0.3

Phải giữ tùy chọn --no-deps vì metadata của MedCLIP 0.0.3 khóa một phiên bản
Transformers cũ, trong khi mã nguồn có lớp tương thích với Transformers hiện
tại. Không sao chép thư viện hoặc thư mục site-packages vào MaDeTai/src.


7. PRETRAINED WEIGHTS
---------------------
Pretrained weights không nằm trong gói mã nguồn. BiomedCLIP, CLIP và PubMedCLIP
được tải qua Hugging Face/OpenCLIP khi cấu hình tương ứng khởi tạo lần đầu.
MedCLIP tải weights qua package MedCLIP. Muốn chạy ngoại tuyến, phải chạy thử
cấu hình cần dùng khi còn mạng để chuẩn bị đầy đủ cache pretrained model trên
máy đích; repository không còn script tải weights riêng.


8. CHUẨN BỊ DỮ LIỆU
--------------------
Dữ liệu không được đóng gói cùng mã nguồn. Sau khi có quyền sử dụng hợp lệ, đặt
dữ liệu đã tiền xử lý theo cấu trúc sau hoặc sửa đường dẫn trong
configs/dataset/*.yaml:

  MaDeTai/src/data/
  |-- BTXRD/
  |   |-- images/
  |   |-- reports/clinical_v2/
  |   |-- btxrd-split.csv
  |   `-- btxrd-labels.csv
  |-- CTCH/
  |   |-- images/
  |   |-- reports/xray/
  |   |-- reports/clinical/
  |   |-- ctch-split.csv
  |   |-- ctch-labels.csv
  |   `-- labels.txt
  `-- FracAtlas/
      |-- images/Fractured/
      |-- images/Non_fractured/
      |-- reports/
      |-- fracatlas-split.csv
      `-- fracatlas-labels.csv

Các file .py có sẵn dưới data/ chỉ là mã tiền xử lý; chúng không chứa mẫu dữ
liệu. Các entrypoint hiện tại là data/BTXRD/preprocess_btxrd.py,
data/BTXRD/generate_clinical_reports.py, data/CTCH/preprocess_ctch.py,
data/FracAtlas/preprocess.py và data/FracAtlas/generate_reports.py. Việc tiền xử
lý chi tiết được mô tả trong HuongDanSuDung.txt.


9. KIỂM TRA CÀI ĐẶT
-------------------
Tại MaDeTai/src, chạy lần lượt:

  python -c "import torch; print(torch.__version__); print(torch.cuda.is_available())"
  python -c "import hydra, numpy, pandas, sklearn, streamlit, transformers; print('Core libraries: OK')"
  python tools/generate_requirement.py --check
  python tools/training.py --dry-run

Nếu dùng MedCLIP, kiểm tra thêm:

  python -c "from src.models.backbone.medclip_foundation import MedCLIPFoundation; print('MedCLIP: OK')"

Lệnh kiểm tra requirements phải thông báo requirements.txt đang đồng bộ. Dry-run
chỉ in danh sách experiment được chọn, không huấn luyện và không tạo checkpoint.


10. LỖI CÀI ĐẶT THƯỜNG GẶP
--------------------------
- ModuleNotFoundError: kiểm tra đã kích hoạt môi trường Thesis và terminal đang
  ở đúng MaDeTai/src.
- torch.cuda.is_available() trả về False: kiểm tra driver bằng nvidia-smi và
  bảo đảm đã cài đúng wheel CUDA thay vì wheel CPU.
- Không tải được pretrained weights: kiểm tra Internet, quyền ghi cache Hugging
  Face và dung lượng đĩa.
- Lỗi MedCLIP/Transformers: cài requirements.txt trước, sau đó cài MedCLIP bằng
  đúng tùy chọn --no-deps.
- Hết bộ nhớ GPU: giảm dataset.batch_size hoặc model.tile_encode_chunk_size;
  hướng dẫn override cụ thể nằm trong HuongDanSuDung.txt.
