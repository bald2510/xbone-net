HƯỚNG DẪN CÀI ĐẶT XBONE-NET
============================

1. PHẠM VI GÓI MÃ NGUỒN
-----------------------
Gói mã nguồn có cấu trúc:

  MaDeTai/
  |-- src/                      Mã nguồn và cấu hình có thể thực thi
  |-- HuongDanCaiDat.txt        Tài liệu hướng dẫn cài đặt môi trường
  |-- HuongDanSuDung.txt        Hướng dẫn chạy huấn luyện, đánh giá & benchmark
  `-- HuongDanSuDungDemo.txt    Hướng dẫn sử dụng ứng dụng Web Demo (Streamlit)

Thư mục MaDeTai/src là thư mục gốc của chương trình (nơi chứa train.py, evaluate.py,
requirements.txt). Bên trong gồm các entrypoint chính: train.py, evaluate.py,
inference.py; package Python src/; cấu hình Hydra configs/;
benchmark/; ứng dụng demo Streamlit trong demo/; công cụ tools/; launcher Windows
trong scripts/; và mã tiền xử lý dữ liệu trong data/.

Gói KHÔNG chứa thư viện bên thứ ba, môi trường Python đã build sẵn, dữ liệu bệnh nhân,
pretrained weights, checkpoint, kết quả log, cache hay file trung gian.
Tệp requirements.txt cung cấp danh sách phiên bản chuẩn hóa để cài đặt toàn diện toàn bộ
chức năng hệ thống (bao gồm cả giao diện demo Streamlit).


2. YÊU CẦU HỆ THỐNG
-------------------
- Hệ điều hành: Windows 10/11 64-bit hoặc Linux 64-bit.
- Phiên bản Python: 3.11 (khuyến nghị Python 3.11.15).
- Công cụ quản lý môi trường: Miniconda hoặc Anaconda.
- GPU: NVIDIA GPU có hỗ trợ CUDA (khuyến nghị VRAM >= 8GB khi huấn luyện).
- CPU: Có thể dùng để kiểm tra cú pháp, suy luận đơn mẫu hoặc chạy demo (tốc độ chậm hơn).
- Dung lượng đĩa: Tối thiểu 10GB trống cho dữ liệu, cache pretrained weights và checkpoints.
- Kết nối Internet: Cần thiết trong lần đầu để tải các pretrained model foundation.


3. MỞ THƯ MỤC CHƯƠNG TRÌNH
--------------------------
Mọi lệnh huấn luyện, đánh giá, suy luận và khởi chạy demo phải thực thi tại MaDeTai/src
để các đường dẫn tương đối và cấu hình Hydra được phân giải chính xác.

Windows PowerShell/CMD:

  cd <DUONG_DAN_DEN_GOI_NOP>\MaDeTai\src

Linux:

  cd <DUONG_DAN_DEN_GOI_NOP>/MaDeTai/src


4. TẠO VÀ KÍCH HOẠT MÔI TRƯỜNG PYTHON
-------------------------------------
  conda create -n Thesis python=3.11.15 -y
  conda activate Thesis
  python -m pip install --upgrade pip setuptools wheel

Kiểm tra môi trường hiện tại:

  python --version

Windows:

  where.exe python

Linux:

  which python


5. CÀI ĐẶT PYTORCH
------------------
Môi trường nghiên cứu sử dụng PyTorch 2.11.0 và torchvision 0.26.0:

NVIDIA GPU (CUDA 12.8 / 12.x):

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu128

Chỉ dùng CPU:

  python -m pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cpu


6. CÀI ĐẶT CÁC THƯ VIỆN CỦA DỰ ÁN
---------------------------------
Tại thư mục MaDeTai/src, thực thi:

  python -m pip install -r requirements.txt

Tệp requirements.txt đã tích hợp đồng bộ toàn bộ thư viện cần thiết cho toàn bộ quy trình:
- Huấn luyện & Đánh giá: accelerate, evaluate, hydra-core, omegaconf, peft, timm, transformers.
- Thị giác & Xử lý ngôn ngữ: open-clip-torch, Pillow, nltk, deep-translator.
- Phân tích & Đồ họa: matplotlib, numpy, pandas, scikit-learn, scipy, tensorboard, tqdm, wget.
- Giao diện người dùng: streamlit.

Lưu ý khi chạy baseline MedCLIP (nếu có):
Chỉ khi cần chạy thực nghiệm so sánh với baseline MedCLIP, cài bổ sung bằng lệnh:

  python -m pip install --no-deps MedCLIP==0.0.3


7. PRETRAINED FOUNDATION WEIGHTS
--------------------------------
Pretrained weights của các mô hình nền tảng (BiomedCLIP, CLIP, PubMedCLIP) sẽ được
tự động tải về từ Hugging Face / OpenCLIP khi cấu hình tương ứng được khởi tạo lần đầu.
Nếu chạy trong môi trường ngoại tuyến, cần cho máy kết nối Internet một lần để nạp cache.

10. XỬ LÝ SỰ CỐ CÀI ĐẶT THƯỜNG GẶP
-----------------------------------
- Lỗi ModuleNotFoundError: Đảm bảo đã kích hoạt conda environment (conda activate Thesis)
  và terminal đang đứng tại đúng thư mục MaDeTai/src.
- Lỗi CUDA không nhận: Chạy lệnh nvidia-smi kiểm tra driver GPU và cài đặt đúng bản PyTorch CUDA.
- Lỗi xung đột MedCLIP: Luôn cài requirements.txt trước, sau đó cài MedCLIP với cờ --no-deps.
- Lỗi hết bộ nhớ GPU (OOM): Giảm batch size thông qua Hydra override (dataset.batch_size=4).
