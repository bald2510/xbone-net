HƯỚNG DẪN SỬ DỤNG XBONE-NET
===========================

1. ĐIỀU KIỆN TRƯỚC KHI CHẠY
---------------------------
- Đã cài đặt môi trường và các thư viện theo hướng dẫn trong HuongDanCaiDat.txt.
- Đã kích hoạt môi trường nghiên cứu:

    conda activate Thesis

- Terminal đang đứng tại thư mục gốc của chương trình: MaDeTai/src.
- Dữ liệu đã được bố trí đúng cấu trúc trong thư mục data/.
- Checkpoint huấn luyện đặt tại thư mục checkpoints/ và phải khớp config trong results/.


2. KIỂM TRA CÚ PHÁP VÀ HỆ THỐNG
-------------------------------
Kiểm tra cú pháp toàn bộ mã nguồn:

  python -m compileall -q train.py evaluate.py inference.py src tools benchmark demo data

Kiểm tra danh mục thư viện đồng bộ:

  python tools/generate_requirement.py --check


3. TIỀN XỬ LÝ DỮ LIỆU
----------------------
(Bỏ qua bước này nếu đã có sẵn các file split CSV và thư mục reports)

3.1. Tập dữ liệu CTCH:
Đặt file data_labeled_full_selected_cleaned.xlsx, images/ và labels.txt trong data/CTCH, sau đó chạy:

  python data/CTCH/preprocess_ctch.py --step all

3.2. Tập dữ liệu BTXRD:
Đặt dataset.csv và ảnh vào data/BTXRD, sau đó chạy:

  python data/BTXRD/preprocess_btxrd.py
  python data/BTXRD/generate_clinical_reports.py

4. HUẤN LUYỆN MÔ HÌNH ĐỀ XUẤT (XBONE-NET)
-----------------------------------------
Huấn luyện XBone-Net trên CTCH (mặc định seed 42):

  python train.py +experiment=ctch/proposed/ours_xbone_net

Huấn luyện XBone-Net trên BTXRD:

  python train.py +experiment=btxrd/proposed/ours_xbone_net

Chỉ định seed khác (ví dụ: seed 123, seed 456):

  python train.py +experiment=ctch/proposed/ours_xbone_net seed=123

Tối ưu bộ nhớ GPU (giảm batch size):

  python train.py +experiment=ctch/proposed/ours_xbone_net dataset.batch_size=4

Trọng số tốt nhất của 2 giai đoạn huấn luyện sẽ được lưu tự động tại:
  checkpoints/<dataset>/proposed/ours_xbone_net/seed_<seed>/best_phase1.pth
  checkpoints/<dataset>/proposed/ours_xbone_net/seed_<seed>/best_phase2.pth


5. ĐÁNH GIÁ PHÂN LOẠI MÔ HÌNH
-----------------------------
Đánh giá trên tập kiểm thử CTCH:

  python evaluate.py +experiment=ctch/proposed/ours_xbone_net

Đánh giá kèm khoảng tin cậy Bootstrap 95% và trích xuất embedding:

  python evaluate.py +experiment=ctch/proposed/ours_xbone_net --bootstrap --n-bootstrap 10000 --save-embeddings


6. SUY LUẬN TRÊN MỘT MẪU ĐƠN LẺ (CLI)
--------------------------------------
Chạy dự đoán cho 1 cặp ảnh X-quang và tiền sử lâm sàng:

  python inference.py +experiment=ctch/proposed/ours_xbone_net --image data/CTCH/images/<TEN_FILE_ANH.jpg> --clinical-text "<NOI_DUNG_TIEN_SU_LAM_SANG>" --checkpoint checkpoints/ctch/proposed/ours_xbone_net/seed_42/best_phase2.pth --device cuda


7. CHẠY CÁC THỰC NGHIỆM ĐỐI CHỨNG (BASELINES & ABLATION)
--------------------------------------------------------
Zero-shot VLM Baseline:

  python evaluate.py +experiment=ctch/baselines/zeroshot/biomedclip_zeroshot

Full Fine-Tuning Baseline:

  python train.py +experiment=ctch/baselines/full_finetuned/fft_biomedclip

Few-Shot Learning (10-shot, 20-shot):

  python train.py +experiment=ctch/few_shot/10_shot/ours_xbone_net

Ablation tiền xử lý (resize trực tiếp thay cho letterbox):

  python train.py +experiment=ctch/ablation_study/architecture/preprocess/direct_resize_current


8. CHẠY NHIỀU SEED HOẶC TỰ ĐỘNG HÓA HÀNG LOẠT
----------------------------------------------
Chạy huấn luyện và đánh giá trên 3 seed (42, 123, 456):

  python tools/training.py --group ctch/proposed/ours_xbone_net --seeds 42 123 456

Tổng hợp bảng so sánh kết quả tự động:

  python tools/training.py --table --group ctch/proposed/ours_xbone_net


9. ĐÁNH GIÁ OOD VÀ TRỰC QUAN HÓA GIẢI THÍCH MÔ HÌNH
----------------------------------------------------
9.1. Đánh giá phát hiện Out-of-Distribution (OOD):

  python benchmark/ood_analysis.py --experiments ctch/proposed/ours_xbone_net --seeds 42 123 456 --device cuda

Đánh giá IG end-to-end trên ảnh letterbox và văn bản (cần feature archive train/test):

  python benchmark/explainability_analysis.py --experiment ctch/proposed/ours_xbone_net --seed 42 --train-features results/ctch/proposed/ours_xbone_net/seed_42/analysis/features/ctch_train.npz --test-features results/ctch/proposed/ours_xbone_net/seed_42/analysis/features/ctch_test.npz --output-dir results/ctch/proposed/ours_xbone_net/seed_42/analysis/explainability --device cuda

9.2. Xuất hình ảnh Integrated Gradients (IG Attribution) đa phương thức:

  python tools/visualize/render_multimodal_ig.py --image-id 3021_img-84263-00001.jpg --device cuda --output results/visualization/multimodal_ig_sample.png

9.3. Xuất hình ảnh Chú ý chéo hai chiều (Cross-Modal Attention):

  python tools/visualize/attention.py --image-id 3021_img-84263-00001.jpg --device cuda


10. ĐO HIỆU QUẢ TÍNH TOÁN (BENCHMARK)
-------------------------------------
Đo GFLOPs, Throughput, Latency và VRAM tiêu thụ:

  python benchmark/efficiency.py +experiment=ctch/proposed/ours_xbone_net ++seed=42 --device cuda --precision fp32 --batch-size 1 --num-batches 20 --warmup 10 --repeats 10


11. TRỰC QUAN HÓA BỔ TRỢ
-------------------------
Trực quan hóa quy trình tiền xử lý ảnh Letterbox Square:

  python tools/visualize/preprocessing.py --image data/CTCH/images/<TEN_FILE_ANH.jpg>

Mô hình đề xuất hiện dùng linear head; công cụ tâm lớp chỉ áp dụng cho các
checkpoint ablation dùng empirical centroid, không áp dụng cho ours_xbone_net.


12. KHỞI CHẠY ỨNG DỤNG WEB DEMO (STREAMLIT)
-------------------------------------------
Để chạy giao diện trực quan hóa tương tác hoàn chỉnh cho người dùng:

  streamlit run demo/streamlit_app.py

Chi tiết cách sử dụng các tính năng giao diện xem tại tệp: HuongDanSuDungDemo.txt.


13. QUẢN LÝ CÁC THƯ MỤC VÀ TỆP SINH RA
--------------------------------------
- checkpoints/: Lưu các trọng số mô hình đã huấn luyện (.pth).
- results/: Chứa các bảng metric (.json), hình ảnh trực quan hóa (.png) và kết quả OOD.
- runs/: Lưu log theo dõi quá trình huấn luyện của TensorBoard.
- outputs/: Chứa cấu hình và log thực thi do Hydra tự động sinh ra.
