HƯỚNG DẪN SỬ DỤNG XBONE-NET
===========================

1. ĐIỀU KIỆN CHUNG
------------------
- Đã cài môi trường theo HuongDanCaiDat.txt.
- Đã chạy "conda activate Thesis".
- Terminal đang đứng tại thư mục chứa train.py.
- Để chạy demo, phải có gói demo/model hợp lệ.
- Để huấn luyện/đánh giá, phải có dữ liệu CTCH hoặc BTXRD tương ứng.


2. KIỂM TRA MÃ NGUỒN VÀ DEMO
----------------------------
  python -m compileall -q train.py evaluate.py inference.py src tools benchmark demo
  python tools/generate_requirement.py --check
  python tools/training.py --list-configs
  python tools/verify_demo_artifacts.py


3. CHẠY DEMO
------------
  python -m streamlit run demo/streamlit_app.py

Chi tiết đầu vào, đầu ra, OOD, IG và xử lý lỗi xem HuongDanSuDungDemo.txt.


4. HUẤN LUYỆN MÔ HÌNH ĐỀ XUẤT
------------------------------
CTCH, seed 42:

  python train.py +experiment=ctch/proposed/ours_xbone_net seed=42

BTXRD, seed 42:

  python train.py +experiment=btxrd/proposed/ours_xbone_net seed=42

Giảm batch size khi thiếu VRAM:

  python train.py +experiment=ctch/proposed/ours_xbone_net seed=42 dataset.batch_size=4

Checkpoint được lưu tại:

  checkpoints/<experiment_name>/seed_<seed>/best_phase1.pth
  checkpoints/<experiment_name>/seed_<seed>/best_phase2.pth


5. ĐÁNH GIÁ PHÂN LOẠI
---------------------
  python evaluate.py +experiment=ctch/proposed/ours_xbone_net seed=42

Bootstrap 95% và lưu embedding:

  python evaluate.py +experiment=ctch/proposed/ours_xbone_net seed=42 --bootstrap --n-bootstrap 10000 --save-embeddings

Kết quả mặc định nằm tại:

  results/ctch/proposed/ours_xbone_net/seed_42/metrics.json


6. CHẠY BA SEED
---------------
tools/experiments.txt có thể disable một config đã hoàn tất. Để lệnh trực tiếp
không bị danh sách disable chặn, luôn dùng --ignore-experiment-file:

  python tools/training.py --group ctch/proposed/ours_xbone_net --ignore-experiment-file --seeds 42 123 456

Xem trước hàng đợi mà không huấn luyện:

  python tools/training.py --group ctch/proposed/ours_xbone_net --ignore-experiment-file --seeds 42 123 456 --dry-run

Tổng hợp kết quả đã có, không huấn luyện lại:

  python tools/training.py --table --group ctch/proposed/ours_xbone_net


7. BASELINE VÀ ABLATION HIỆN CÓ
------------------------------
Liệt kê config thực tế trước khi chạy:

  python tools/training.py --list-configs

Ví dụ:

  python evaluate.py +experiment=ctch/baselines/zeroshot/biomedclip_zeroshot
  python train.py +experiment=ctch/baselines/full_finetuned/fft_biomedclip seed=42
  python train.py +experiment=ctch/ablation_study/architecture/fusion/concat seed=42
  python train.py +experiment=ctch/ablation_study/architecture/phase/phase2_only seed=42

Không sử dụng các lệnh few-shot hoặc config đã bị xóa khỏi --list-configs.


8. OOD VÀ EXPLAINABILITY
------------------------
Trích xuất feature và đánh giá OOD cho seed 42:

  python benchmark/ood_analysis.py --experiments ctch/proposed/ours_xbone_net --seeds 42 --scenarios semantic_ood --device auto

Đánh giá IG trên feature train/test:

  python benchmark/explainability_analysis.py --experiment ctch/proposed/ours_xbone_net --seed 42 --train-features results/ctch/proposed/ours_xbone_net/seed_42/analysis/features/ctch_train.npz --test-features results/ctch/proposed/ours_xbone_net/seed_42/analysis/features/ctch_test.npz --output-dir results/ctch/proposed/ours_xbone_net/seed_42/analysis/explainability --device auto

Xuất một hình IG:

  python tools/visualize/render_multimodal_ig.py --experiment ctch/proposed/ours_xbone_net --image-id 3021_img-84263-00001.jpg --seed 42 --device auto --ig-steps 24 --output results/visualization/multimodal_ig_3021.png


9. ĐO CHI PHÍ SUY LUẬN
----------------------
  python benchmark/efficiency.py +experiment=ctch/proposed/ours_xbone_net ++seed=42 --device auto --precision fp32 --batch-size 1 --num-batches 20 --warmup 10 --repeats 10


10. CẬP NHẬT GÓI MODEL CHO DEMO
--------------------------------
Sau khi huấn luyện và chạy OOD để tạo ctch_train.npz/ctch_val.npz:

  python tools/package_demo_artifacts.py
  python tools/verify_demo_artifacts.py

Công cụ chỉ chấp nhận checkpoint canonical seed 42 với direct_resize,
cross-attention và linear head. Gói đầu ra nằm tại demo/model.


11. THƯ MỤC ĐẦU RA
------------------
- checkpoints/: checkpoint huấn luyện.
- results/: metrics, feature archive, OOD, IG và efficiency.
- outputs/: log/config do Hydra sinh ra.
- demo/model/: gói checkpoint và feature tối thiểu để phát hành demo.
